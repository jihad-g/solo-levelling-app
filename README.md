# Life Leveling

A Solo Leveling style "System" for real life. Flutter, Android first.

See `CLAUDE.md` for the game rules, code map and roadmap.

## Get the app on your phone

Every push builds an APK on GitHub Actions. Open the repo's **Releases** page on the phone, download the newest `life-leveling-build-N.apk`, and install it (allow "install unknown apps" for your browser once).

## Develop

```
flutter pub get
flutter analyze
flutter test
flutter run
```
